# 制作流程

## 1. 确认输入

检查角色全身图的完整性，确认头身比例、四肢、服装与配饰，并识别现有视角。记录角色所需的表情、手指和摆动部位。

### 单张正面图

先询问用户：“目前只有正面图，是否使用 Image 补一张包含正面、侧面和背面的三视图，供你确认后用于建模？”

- **同意生成**：调用当前 Agent 的 **Image 图像生成/编辑工具**，将原图作为图像参考，生成三视图。
- **自行提供**：等待用户补充视图，再检查一致性。
- **仅用正面图继续**：确认用户接受侧面与背面细节需要推定，检查当前 Charakuru 阶段的输入要求。需要额外视图的阶段保持待处理，用户可选择补图或重新授权生成。

Image 使用当前宿主提供的图像工具；缺少该能力时提示用户接入或自行提供视图。生成前遵循宿主的额度与费用提示，在用户同意的范围内执行。

### 三视图要求

以原图保持角色身份、颜色、比例、服装和配饰一致。正面、侧面、背面使用一致的站姿、身高和脚底基线，头顶、耳朵及双脚完整可见。明确每个视角，背面呈现角色背部结构。原图未展示的细节作为补全设计供用户确认。

保存原图和生成图，登记补充视图：

```sh
python3 scripts/workflow.py references projects/my-avatar /path/to/three-views.png
```

可传入多张图片。登记后展示三视图结果。用户确认或提出修改后，完成所需调整，再将 `reference` 检查项记录为通过，进入模型生成。已有完整三视图时直接检查与确认。

## 2. 生成与组装

在 Charakuru 中创建项目，按安装版本的说明制作分部参考、选择模型候选，并完成分割、坐标处理、UV、贴图和组装。

保存各部件的生成任务地址、状态和原始下载文件。检查正面、侧面和背面的形体与连接，向用户展示比例及外观，确认后进入绑定。

## 3. 骨骼与权重

根据角色比例布置髋、脊柱、胸、颈、头、肩、臂、腕掌、腿与脚的骨骼。有手指的角色增加相应指骨。检查可变形顶点的权重覆盖和归一化。

使用抬手、弯肘、翻腕、弯膝和转头等姿势检查关节变形，调整服装和配饰的跟随关系。

## 4. 表情与物理

根据角色设计制作眨眼、张嘴及所需口型，并设置 VRM 表达绑定。固定五官的设计在模型说明中注明。

为头发、长耳、尾巴等摆动部位设置骨骼、权重、物理参数和碰撞体，通过运动测试检查根部稳定性和动态效果。

## 5. 导出与测试

导出前确认模型名称、作者和使用条件，写入 VRM 元数据。打包源文件所需贴图，导出 VRM，在独立场景重新导入，核对材质、贴图、骨骼、表情和物理。随后在 XR Animator 中载入最终文件，完成 [模型与动作检查](ACCEPTANCE.md)。

## 任务记录

生成前读取 Tripo 当前阶段费用与余额，在用户授权预算内执行。按以下顺序记录任务：

```sh
python3 scripts/workflow.py task projects/my-avatar head-geometry-01 intent
python3 scripts/workflow.py task projects/my-avatar head-geometry-01 submitted --url 'https://studio.tripo3d.ai/实际任务路径'
python3 scripts/workflow.py task projects/my-avatar head-geometry-01 completed
```

提交后将 URL 替换为该任务的实际地址；可通过 `--credits` 记录已核实的消耗。下载并检查生成结果后标记完成。

结果未知时查询原任务。确认失败或取消后，如需重试，为新尝试建立关联记录，并重新检查剩余预算。失败任务核对状态及积分处理后，用报告关闭该尝试：

```sh
python3 scripts/workflow.py resolve-task projects/my-avatar head-geometry-01 --evidence projects/my-avatar/reports/task-resolution.md
```

## 项目保存

每个角色使用独立项目目录，保存原始文件、编辑源文件和可用版本。修改模型后，将受影响的检查项更新为 `pending`，对新导出文件复测。检查报告记录模型文件的 SHA-256，以便对应版本。
