# 制作流程

## 1. 确认输入

检查角色全身图的完整性，确认头身比例、四肢、服装与配饰。需要补充视图时先展示参考图供用户确认。记录角色所需的表情、手指和摆动部位。

## 2. 生成与组装

在 Charakuru 中创建项目，按安装版本的说明制作分部参考、选择模型候选，并完成分割、坐标处理、UV、贴图和组装。

保存各部件的生成任务地址、状态和原始下载文件。检查正面、侧面和背面的形体与连接，向用户展示比例及外观，确认后进入绑定。

## 3. 骨骼与权重

根据角色比例布置髋、脊柱、胸、颈、头、肩、臂、腕掌、腿与脚的骨骼。有手指的角色增加相应指骨。检查可变形顶点的权重覆盖和归一化。

使用抬手、弯肘、翻腕、弯膝和转头等姿势检查关节变形，调整服装和配饰的跟随关系。

## 4. 表情与物理

根据角色设计制作眨眼、张嘴及所需口型，并设置 VRM 表达绑定。固定五官的设计在模型说明中注明。

为头发、长耳、尾巴等摆动部位设置骨骼、权重、物理参数和碰撞体，通过运动测试检查根部稳定性和动态效果。

## 5. 导出与测试

导出 VRM，在独立场景重新导入，核对材质、贴图、骨骼、表情和物理。随后在 XR Animator 中载入最终文件，完成 [模型与动作检查](ACCEPTANCE.md)。

## 任务记录

生成前读取 Tripo 当前阶段费用与余额，在用户授权预算内执行。按以下顺序记录任务：

```sh
python3 scripts/workflow.py task projects/my-avatar head-geometry-01 intent
python3 scripts/workflow.py task projects/my-avatar head-geometry-01 submitted --url 'https://studio.tripo3d.ai/实际任务路径'
python3 scripts/workflow.py task projects/my-avatar head-geometry-01 completed
```

提交后将 URL 替换为该任务的实际地址；可通过 `--credits` 记录已核实的消耗。下载并检查生成结果后标记完成。

结果未知时查询原任务。确认失败或取消后，如需重试，为新尝试建立关联记录，并重新检查剩余预算。

## 项目保存

每个角色使用独立项目目录，保存原始文件、编辑源文件和可用版本。修改模型后，将受影响的检查项更新为 `pending`，对新导出文件复测。检查报告记录模型文件的 SHA-256，以便对应版本。
