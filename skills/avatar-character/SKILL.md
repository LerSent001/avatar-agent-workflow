# 角色制作

将用户的角色图片交给 Avatar Agent Workflow，完成参考图确认、模型制作、绑定和 XR Animator 测试。

## 启动

- 用户仅要求安装本 Skill 时，完成入口安装即可。Blender、插件、Charakuru、XR Animator 及运行环境在首次制作时准备。
- 用户要求制作时，先读取当前聊天或用户指定的项目记录。有正在制作的项目，使用该项目保存的工作流路径和进度继续。
- 新项目：确认 Python 3.9+ 可用。缺少时先询问用户是否安装。然后运行本 Skill 目录下的 `scripts/resolve_workflow.py`，取得本地工作流目录；它只获取本项目的固定版本代码。
- 读取返回目录中的 `AGENTS.md`，以该目录作为工作流命令的工作目录。项目保存到用户选择的独立位置，并记录工作流路径，便于后续恢复。
- 没有图片时请用户提供图片；用户已有三视图或模型时读取现有素材，按其请求继续。

## 制作要求

首次制作运行工作流的 `doctor`，按其结果检查软件、版本和插件。可用的直接复用；缺少或不兼容的依赖，列出安装/升级项，得到用户同意后安装，复检通过再制作。安装 Skill 本身不代表用户同意安装这些依赖。

只有正面图时，先询问是否使用 Image 生成三视图；用户同意后使用宿主的 Image 图像工具并展示结果确认。缺少图像或电脑操作能力时说明需要接入的能力。

Tripo 由用户在官方页面登录或注册。核实积分及阶段预算，积分不足时提示用户处理并保存进度。XR Animator 是模型检查环节的必需应用；真人测试按实际结果记录。

遵循用户当前的范围和费用限制。完成后提供 VRM、Blender 源文件、参考图、检查资料和加载说明。
